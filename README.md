# CourseFlow — Personal Course Organizer

A redesigned version of the Personal Course Organizer frontend project.

## Features
- Responsive multi-page layout
- Semantic HTML structure
- Modern course cards
- Add-course form with browser validation
- LocalStorage demo for newly added courses
- Contact form interaction
- Mobile-friendly navigation
- Accessible labels and descriptive page metadata

## Pages
- `index.html` — Home
- `my_courses.html` — Course dashboard
- `add_course.html` — Add a course
- `contact.html` — Contact

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage

This is a frontend practice project.
